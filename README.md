# homebrew-tap

Homebrew tap for [YoannDev90](https://github.com/YoannDev90)'s command-line tools.

Formulae in this repository are **generated and pushed automatically** on every
release of [`android-tools`](https://github.com/YoannDev90/android-tools).
Do not edit them by hand — they will be overwritten.

## Usage

```bash
brew install YoannDev90/homebrew-tap/<tool>
```

To see what is available:

```bash
brew search YoannDev90/homebrew-tap/
```
